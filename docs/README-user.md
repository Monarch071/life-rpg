# Life RPG — как пользоваться (итоговая инструкция)

Это игра, где реальные дела прокачивают твоего героя. Приложение работает бесплатно: сайт размещён на GitHub Pages, сервер синхронизации — на Cloudflare.

## 1. Установка на iPhone

1. Открой в Safari ссылку на приложение.
2. Нажми «Поделиться» → «На экран Домой».
3. Дальше открывай приложение только с экрана «Домой». Иначе не будут работать уведомления и офлайн-режим.
4. После каждого обновления закрой приложение полностью (смахни вверх) и открой снова.

## 2. Первый запуск

1. Пройди анкету: «Герой» → «Создание персонажа». По ней считаются стартовый уровень, характеристики и навыки.
2. Включи синхронизацию: «Настройки» → «Синхронизация». Это нужно, чтобы данные не пропали и чтобы заработали «Команды» и уведомления. Токен сохрани в Заметки.
3. По желанию подключи ИИ: «Настройки» → «ИИ». Подойдёт бесплатный ключ Gemini. ИИ пишет тексты заданий, портрет героя и разбор недели.
4. Поставь своего героя на главный экран: «Герой» → «Арт героя». Можно загрузить свою картинку или попросить ИИ нарисовать героя по фото.

## 3. Каждый день

- **Утро.** В «Мой день» выбери тип дня и отметь, сколько сил (1–10). Приложение соберёт задания под твой день.
- **Днём.** Отмечай выполненные задания галочкой или фото. Шаги, сон и тренировки засчитываются сами через «Команды».
  - «Перебросить» — заменить задание: один раз в день бесплатно, дальше за золото.
  - «День изменился» — если планы поменялись.
  - «Своё задание» — до 2 в день.
- **Вечер.** Сделай чек-ин: отметь ритуалы лестниц и срывы Врага-тени.
- **Воскресенье.** Получаешь ранг недели и разбор от Мастера.

## 4. Где что лежит

- **Главная** — герой, характеристики, HP, Energy, Фокус и Усталость, задания, призрак.
- **Задания** — босс сезона, сюжетная цепочка, недельные задания, прежние цели.
- **Герой** — класс, продвинутый и легендарный путь, способности, навыки и перки, лестницы привычек, Враг-тень, достижения, зал славы, гардероб.
- **Анализ** — «Прогресс» (графики, индекс роста, карточка «до и после») и «Финансы».
- **Магазин** — твои награды за золото и вещи для аватара.
- **Настройки** — синхронизация, ИИ, уведомления, типы дней, тема сезона, валюта, резервная копия.

## 5. Автоматизация

Пошаговая настройка «Команд» описана в `docs/shortcuts.md`. Начни с одной автоматизации — «Выключение будильника» (сон и пульс). Остальные добавляй по одной.

## 6. Бэкап и перенос на другое устройство

- **Синхронизация** переносит всё на новое устройство: на старом устройстве нажми «Ссылка для входа» и открой её на новом.
- **Резервная копия:** «Настройки» → «Экспорт» сохраняет файл. Делай её раз в неделю. Приложение напомнит, если копия старше 7 дней.

## 7. Приватность

- Ключ ИИ хранится только на телефоне и отправляется только выбранному провайдеру.
- Чувствительные ответы анкеты, финансы, траты, места, время в приложениях и грани Тени в ИИ не попадают.
- Фото-подтверждения хранятся только на телефоне. Фото для аватара отправляется в ИИ только после твоего подтверждения и нигде не сохраняется.
- Все данные лежат на телефоне и на твоём собственном сервере Cloudflare.
