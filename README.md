# Life RPG

Приложение для iPhone (PWA), которое превращает твой день в RPG: задания на день, опыт, характеристики героя и «Тень», с которой ты соревнуешься. Все данные хранятся на телефоне.

## Запуск локально

```
npm install
npm run dev
npm test
```

Сборка: `npm run build`, проверка сборки: `npm run preview`.

## Структура

- `src/domain/` — игровая логика (XP, характеристики, задания, расписание, Тень)
- `src/screens/` — экраны (анкета, «Мой день», персонаж, настройки)
- `src/ui/` — общие компоненты (аватар, диалоги, сохранение файла)
- `src/db.ts`, `src/backup.ts` — хранилище событий (IndexedDB) и экспорт/импорт
- `.github/workflows/deploy.yml` — публикация на GitHub Pages

## Финансы и импорт выписки

«Анализ → Финансы»: записи расходов, доходов и «отложено», категории с месячными лимитами, правила магазинов и импорт выписки банка.

**Формат CSV.** Любая выгрузка банка в CSV (до 2 МБ, до 5 000 строк): разделитель `;`, `,` или табуляция, кодировка UTF-8, первая строка — заголовки. Нужны колонки:

- дата — `дд.мм.гггг`, `дд.мм.гг`, `гггг-мм-дд` или `дд/мм/гггг` (время после даты допускается);
- сумма — одна колонка со знаком (минус — списание) или пара «Списание / Поступление»;
- описание (необязательно) — сохраняется первые 60 символов.

Колонки угадываются по заголовкам (`Дата`, `Сумма`, `Списание`, `Поступление`, `Описание`, `Date`, `Amount`, `Description`…); если не вышло — выбираются вручную, выбор запоминается на устройстве. Пример (вымышленный):

```
Дата;Сумма;Описание
05.01.2027;-350,00;Магазин 1
06.01.2027;1 200,50;Перевод
```

Перед записью показывается предпросмотр: новых строк, дублей с тратами Wallet, уже импортированных и пропущенных (с номером строки и причиной). Повторный импорт того же файла не создаёт дублей. Импорт удаляется целиком в том же листе.

**Что никуда не отправляется.** Файл читается и разбирается только на телефоне и не сохраняется. В журнал попадают дата, сумма и короткое описание — они живут на устройстве и уходят только в твою собственную синхронизацию. Финансовые данные не передаются в ИИ (ни в задания, ни в отчёты, ни в разбор сезона — «Аудит» Казначея считается правилами на устройстве), не показываются в уведомлениях и не попадают на карточку «до и после» (рекорд накоплений — без суммы).
